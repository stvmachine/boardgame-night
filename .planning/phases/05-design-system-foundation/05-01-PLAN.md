## Phase Goal

**As a** user of the boardgame night app, **I want to** see the app rendered with the Tabletop Social Material 3 design system (Inter font, indigo primary, M3 tonal palette, Material Symbols icons), **so that** the app feels modern and consistent across all surfaces.

> Adapted from ROADMAP Phase 5 goal: "The app renders with the 'Tabletop Social' design system and a shared set of primitives so all redesigned surfaces can be built consistently."

<objective>
Establish the Tabletop Social Material 3 design system infrastructure: generate M3 tonal palettes from the indigo seed, install shadcn-vue/reka-ui dependencies, run shadcn-vue init, override all CSS variables with M3 tokens, and set up Inter font + Iconify icon infrastructure + cn() utility.

Purpose: This plan delivers the token system and tooling foundation that Plan 05-04 (primitive scaffolding) builds on. Without M3 tokens, Inter font, and the shadcn-vue configuration, no primitive can be styled consistently. Per D-01, D-05, D-07, D-09, D-10, D-11, D-12, this is the one-time infrastructure investment.

Output: Committed M3 token CSS (light + dark), Inter font import, Iconify Icon wrapper, cn()/cva utility, shadcn-vue components.json config, and the build-time M3 token generation script. Primitive scaffolding is deferred to Plan 05-04.
</objective>

## Phase Goal

**As a** user of the boardgame night app, **I want to** see the app rendered with the Tabletop Social Material 3 design system (Inter font, indigo primary, M3 tonal palette, Material Symbols icons), **so that** the app feels modern and consistent across all surfaces.

> Adapted from ROADMAP Phase 5 goal: "The app renders with the 'Tabletop Social' design system and a shared set of primitives so all redesigned surfaces can be built consistently."

<objective>
Establish the Tabletop Social Material 3 design system foundation: generate M3 tonal palettes from the indigo seed, install shadcn-vue/reka-ui primitives, override all primitive CSS variables with M3 tokens, and set up Inter font + Iconify icon infrastructure.

Purpose: This plan delivers the token system and primitive library that all v1.1 phases (8-10) build on. Without M3 tokens and styled primitives, no redesigned surface can be built consistently. Per D-01 through D-09, this is a one-time foundation investment.

Output: Committed M3 token CSS, 15 scaffolded primitives with M3 overrides, Inter font import, Iconify Icon wrapper, cn()/cva utility, and the build-time M3 token generation script.
</objective>

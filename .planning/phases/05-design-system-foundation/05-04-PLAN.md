## Phase Goal

**As a** user of the boardgame night app, **I want to** see UI elements (buttons, cards, badges, avatars, skeletons) rendered with the Tabletop Social Material 3 design system, **so that** the app feels visually consistent and modern across all surfaces.

> Adapted from ROADMAP Phase 5 goal: "The app renders with the 'Tabletop Social' design system and a shared set of primitives so all redesigned surfaces can be built consistently."

<objective>
Scaffold all 15 shadcn-vue/reka-ui primitives (Button, Input, Badge, Card, Avatar, Skeleton, Dialog, DropdownMenu, Select, Tooltip, Tabs, Checkbox, Collapsible, Sheet) and override every primitive's CSS variables with M3 tokens from Plan 05-01.

Purpose: This plan delivers the primitive library that all v1.1 phases (8-10) and Plan 05-02 (app shell) build on. Per D-06, D-07, D-08, shadcn-vue CLI scaffolds component source files (full ownership), and we override all default CSS variables with M3 tonal palette tokens. This is the one-time primitive setup.

Output: 15 scaffolded primitives with M3 token overrides, cva variant definitions for Button and Badge, and Vitest component tests verifying M3 token styling.
</objective>

**As a** board game night organizer, **I want to** trigger a BGG collection import and watch its progress in real time, **so that** I can trust the merged collection is up to date.

<objective>

Purpose: Enables users to pull fresh BGG data, see progress, and create/join game-night groups and sessions.
Output: ImportCollection mutation + job, UserSyncUpdated subscription, group/session mutations, Solid Cable wiring.
</objective>

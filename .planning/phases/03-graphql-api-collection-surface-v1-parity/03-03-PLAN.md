<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL bar ↔ Vue state | Permalink params are untrusted input that hydrate filter state. |
| Browser → Rails /graphql | Queries are read-only in this plan; mutations were hardened in Plan 02. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Information Disclosure | GraphQL introspection | medium | mitigate | Already disabled in production by `BoardgameNightSchema`. |
| T-03-03-02 | Denial of Service | Fuse.js on huge collections | medium | mitigate | Client-side only; v1 scope assumes friend-group sizes (3–10 users, ~200 games each) per CONTEXT.md deferred server-side search. |
| T-03-03-03 | Cross-Site Scripting | Search/group labels rendered from URL params | high | mitigate | All dynamic text rendered with `{{ }}` (Vue text interpolation); never use `v-html` for user-controlled params. |
| T-03-03-04 | Information Disclosure | Permalink leaks selected usernames/filters in browser history | low | accept | v1 collections are public BGG data; URL state is intentional sharing mechanism. |
| T-03-03-05 | Tampering | npm installs (fuse.js, @vueuse/integrations) | high | mitigate | Both packages have OK legitimacy verdict from RESEARCH.md; slopcheck before install. |
</threat_model>

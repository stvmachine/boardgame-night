## Phase Goal

**As a** board game night organizer, **I want to** manually refresh a collector's BGG collection with a 15-minute cooldown and see when it was last synced, **so that** I can get fresh data without hammering the BGG API.

<objective>
Close Gap 3 (frontend half) from 03-VERIFICATION.md: No refresh button in the UI. Add a per-user RefreshButton component with countdown timer, a useRefreshCollection composable that tracks per-user cooldown state, wire CollectorsSection @refresh events through the Sidebar to the composable, and ensure the merged_collection GraphQL query requests lastSyncedAt for client-side cooldown computation.

This plan depends on 03-10 (backend), which adds the cooldown-enforced importCollection mutation, persists last_synced_at, and caches BGG collection responses.

Purpose: Delivers the manual refresh UI promised by COLL-18 and D-12, with per-user cooldown state so refreshing one collector does not disable the button for others.
Output: RefreshButton component, useRefreshCollection composable (per-user cooldown), CollectorsSection refresh wiring, Sidebar composable integration.
</objective>

## Phase Goal

**As a** board game night organizer, **I want to** manually refresh a collector's BGG collection with a 15-minute cooldown and see when it was last synced, **so that** I can get fresh data without hammering the BGG API.

<objective>
Close Gap 3 (backend half) from 03-VERIFICATION.md: No per-user cooldown enforcement, no persisted last_synced_at, and no stale-while-revalidate caching for the BGG collection fetch. Enforce a 15-minute cooldown per username in the importCollection mutation, persist last_synced_at on the User model, cache BGG collection responses with stale-while-revalidate, and align ImportCollectionJob retry/discard declarations with Bgg::* error classes (CR-01).

The frontend half (RefreshButton, useRefreshCollection, CollectorsSection/Sidebar wiring) is plan 03-11, which depends on this plan.

Purpose: Delivers the backend cooldown + stale-while-revalidate + last_synced_at persistence promised by COLL-18 and D-12, plus the CR-01 error-class alignment from 03-REVIEW.md.
Output: last_synced_at migration, cooldown-enforced mutation, cached BGG client collection fetch, CR-01-fixed job error handling.
</objective>

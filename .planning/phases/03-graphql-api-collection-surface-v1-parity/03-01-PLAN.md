## Phase Goal

**As a** board game night organizer, **I want to** merge my friends' BGG collections and browse them in a responsive UI, **so that** I can quickly see which games the group owns together.

<objective>
Deliver the end-to-end read path for merged BGG collections (D-02, D-08): persist statistics columns, expose a Dataloader-backed `mergedCollection` GraphQL query, and render game cards in a minimal `/collection` view.

Purpose: This is the first vertical slice of Phase 3 — it proves the DB → GraphQL → Vue pipeline for collection browsing before adding import/sync interactivity.
Output: Migrated statistics columns, GraphQL types, Dataloader loaders, minimal CollectionView with GameCard/GameGrid, and regenerated codegen operations.
</objective>

## Phase Goal

**As a** board game night organizer, **I want to** validate BGG usernames, import collections, and watch real-time sync status, **so that** I can build a merged collection from fresh data without guessing when imports finish.

<objective>
Deliver the import and sync vertical slice (D-06, D-09, D-10, D-11, D-12): dry-rails validated mutations, Solid Cable subscriptions with real-time job broadcasts, landing page with hot items, and a sidebar that shows per-user sync status and refresh controls.

Purpose: Turns the read-only collection view from Plan 01 into an interactive surface where users can add collectors and see import progress.
Output: Subscription type, mutations with contracts, Solid Cable schema, updated ImportCollectionJob, Apollo split link, Landing/Hot views, search query, sidebar sync components, and ADRs for key decisions.
</objective>

## Phase Goal

**As a** board game night organizer, **I want to** merge my friends' BGG collections and browse them in a responsive UI, **so that** I can quickly see which games the group owns together.

<objective>
Wire the first end-to-end read path: expose the `mergedCollection` and `user` GraphQL queries and render a minimal collection grid in the browser.

Purpose: Proves the DB → GraphQL → Vue pipeline for collection browsing before adding import/sync interactivity.
Output: QueryType fields, minimal CollectionView with GameCard/GameGrid, and regenerated codegen outputs.
</objective>

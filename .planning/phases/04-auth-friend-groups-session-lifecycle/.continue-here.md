# Decisions Made

- **Auth session:** Rails 8 built-in authentication generator adapted for API-only Bearer tokens. Token stored in JS memory/Pinia, sent via Apollo `setContext` link. Logout destroys `Session` row.
- **No-account RSVP:** Provisional `User` rows with `provisional:boolean` and auto-generated `guest_*` username. Upgrade to full account is a single `UPDATE`. GraphQL `UserType` gets `isProvisional` and `displayName`.
- **Magic-link invitations:** Persisted `InviteToken` table with SHA-256 hashed CSPRNG tokens. Supports audit, revocation, existing-user join, new-user handoff, and no-account RSVP.
- **Group collection view:** Dynamic computation via existing `BggThing.merged_for_users` and `OwnersLoader`. No snapshot table or cache for v1.
- **Session lifecycle:** Manual 4-state machine: `draft → invited → picking → completed`. Host-driven transitions via explicit mutations.

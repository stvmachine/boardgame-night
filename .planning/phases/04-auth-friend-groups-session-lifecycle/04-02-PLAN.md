## Phase Goal

**As a** user, **I want to** create friend groups and invite others via magic links, **so that** I can merge our BGG collections into a shared view and organize game nights together.

<objective>
Deliver the friend groups vertical slice: Group + GroupMembership + InviteToken models, createGroup/inviteToGroup/acceptGroupInvite/removeMember/updateRole mutations with dry-validation contracts, GroupType with dynamic merged collection view, InviteMailer for magic-link email delivery, and Vue group list/detail views with invite link UI and member management.

Purpose: Groups are the container for sessions and the shared collection view. The invite token table (ADR-010) provides auditable, revocable magic-link invitations for both group joins and (in Plan 04-03) session RSVPs.

Output: Working group creation, invitation, join, and member management flow end-to-end with RSpec model+mutation+mailer specs.
</objective>

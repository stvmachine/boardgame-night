## Phase Goal

**As a** user, **I want to** create an account, log in, and bind my BGG username, **so that** I can persist my identity and link my board game collection to the app.

<objective>
Deliver the full auth vertical slice: Rails 8 authentication generator adapted for API-only Bearer tokens, Session model, Current/Authentication concern, signUp/signIn/signOut/bindBggUsername GraphQL mutations with dry-validation contracts, Apollo setContext auth link, Vue auth forms, and protected route guards.

Purpose: Establish the authentication foundation that all subsequent Phase 4 features (groups, sessions, RSVP) depend on. Every later mutation reads `context[:current_user]` resolved from the Bearer token.

Output: Working signup/login/logout/binding flow end-to-end, with RSpec model+mutation specs and Vitest store+view specs.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | signIn mutation | high | mitigate | Rack::Attack throttle: 5 login attempts/min per IP on POST /graphql containing signIn operations |
| T-04-02 | Tampering | Session token | high | mitigate | has_secure_token generates CSPRNG tokens; token stored as plain string in DB, indexed uniquely; 30-day expiry |
| T-04-03 | Information Disclosure | Auth token storage | medium | mitigate | Token stored in Pinia memory-only ref (never localStorage); lost on page refresh requires re-login per D-01 |
| T-04-04 | Elevation of Privilege | Authenticated mutations | high | mitigate | Every protected mutation checks `context[:current_user]` and raises GraphQL::ExecutionError if nil |
| T-04-05 | Information Disclosure | Error messages | medium | mitigate | signIn returns identical "Invalid credentials" for wrong email and wrong password to prevent user enumeration |
| T-04-SC | Tampering | bundler/npm installs | high | mitigate | bundler-audit + brakeman already in Gemfile; no new npm packages in this plan (setContext is part of @apollo/client already installed) |
</threat_model>

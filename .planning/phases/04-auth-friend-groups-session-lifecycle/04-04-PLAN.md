## Phase Goal

**As a** session host, **I want to** pick a game from our group's shared collection and advance the session through its lifecycle, **so that** we know what we're playing tonight.

<objective>
Deliver the game picking + lifecycle completion vertical slice: startPicking/pickGame/cancelSession/reopenSession mutations with state-transition contracts, GamePicker component (reuses collection grid filtered by attendee count), SessionSummary (read-only completed view), state transition buttons, and an end-to-end Playwright test covering the full session lifecycle.

Purpose: This completes the session lifecycle (SESS-06) and delivers the manual game picking surface (SESS-05) that replaces the deferred suggestion engine. The state machine guards (ADR-012) ensure sessions cannot skip states or be picked in the wrong state.

Output: Working game picking + lifecycle completion flow end-to-end with RSpec mutation specs and a Playwright e2e test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → GraphQL API | All lifecycle mutations require host auth (Bearer token) |
| State machine | Invalid transitions are rejected by guard clauses; no client can skip states |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-18 | Tampering | pickGame in wrong state | high | mitigate | State guard: `raise ExecutionError unless session.state == 'picking'` (D-12, ADR-012) |
| T-04-19 | Elevation of Privilege | Non-host picks game | high | mitigate | Mutation verifies `session.host_id == context[:current_user].id` before any state transition (D-12) |
| T-04-20 | Tampering | pickGame with game not in collection | medium | mitigate | Mutation validates `BggThing.merged_for_users(group.member_ids).exists?(id: game_id)` before accepting (SESS-05) |
| T-04-21 | Tampering | cancelSession on completed session | medium | mitigate | State guard: `can_cancel?` only allows cancellation from draft/invited/picking, not completed (D-12) |
| T-04-22 | Repudiation | Session lifecycle transitions | low | mitigate | State changes are persisted with `previous_state` for cancel/reopen audit trail; all mutations require authenticated host |
| T-04-SC | Tampering | No new packages in this plan | low | accept | All mutations use existing gems; Playwright already installed |
</threat_model>

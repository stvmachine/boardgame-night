<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → collection URL | User-entered BGG usernames become shareable URL state. |
| Rails GraphQL → Home/Hot | External BGG-derived data crosses the API boundary before rendering. |
| External BGG link → new tab | Card activation leaves the application origin. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-02-01 | Tampering | `CollectionMergeForm` URL input | medium | mitigate | Trim/deduplicate entries, encode URL values, and leave authoritative username validation/import to Rails. |
| T-13-02-02 | Information Disclosure | Dashboard statistics | medium | mitigate | Render only the authorization-scoped GraphQL response; never substitute fabricated shared metrics. |
| T-13-02-03 | Spoofing | Mobile quick-action routes | medium | mitigate | Derive destinations only from `ActiveGroupContext` or known application routes; remove fixed tokens. |
| T-13-02-04 | Elevation of Privilege | Anonymous quick-start | high | mitigate | Keep the existing `CREATE_ANONYMOUS_GROUP` backend mutation as authority; do not infer privileged role client-side. |
| T-13-02-05 | Tampering | BGG external links | medium | mitigate | Build URLs from backend object identity and isolate new tabs with `noopener noreferrer`; render all text through React escaping. |
</threat_model>

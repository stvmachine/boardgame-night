<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL → collection state | Untrusted source/filter parameters select data and drive rendering. |
| Client → Group.collection | Group token crosses an authorization boundary enforced by Rails. |
| Game card → BGG | Backend identity becomes an external destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-03-01 | Tampering | `fromParams` | medium | mitigate | Allowlist enum values, clamp numbers, discard malformed ranges, and preserve reserved source keys separately. |
| T-13-03-02 | Information Disclosure | GroupCollection | high | mitigate | Consume the existing server-authorized `Group.collection`; never reconstruct group membership authorization in React. |
| T-13-03-03 | Denial of Service | simultaneous queries/grouping | medium | mitigate | Enforce one source query per route and memoize bounded client transforms over the returned collection. |
| T-13-03-04 | Spoofing | owner grouping | low | accept | Labels use backend-provided BGG usernames; grouping grants no authority. |
| T-13-03-05 | Tampering | BGG card activation | medium | mitigate | Use persisted object identity, React text escaping, one isolated overlay anchor, and nested-control pointer/keyboard isolation. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Viewer/host → session mutations | Client role presentation crosses server authorization and lifecycle validation. |
| GraphQL suggestion → rendered/picked game | Backend-ranked content and identity drive external links and the pick mutation. |
| Full browser suite → mutable E2E state | Tests seed and restore shared development fixtures/databases. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-06-01 | Elevation of Privilege | schedule/start/edit/pick controls | high | mitigate | Hide controls by authenticated host identity for usability and retain Rails authorization on every mutation; cover non-host cases. |
| T-13-06-02 | Tampering | PickGame selection/cache | high | mitigate | Submit only a server-returned eligible suggestion id, disable competing submissions, and transition only from mutation-returned session state. |
| T-13-06-03 | Information Disclosure | attendee/suggestion data | medium | accept | Authorized group/session viewers intentionally see this data; no token, email, or BGG credential is rendered. |
| T-13-06-04 | Tampering | descriptions/reasons/external links | medium | mitigate | Render through React escaping, prohibit HTML injection, use persisted objectid, and isolate new tabs. |
| T-13-06-05 | Denial of Service | browser acceptance suite | medium | mitigate | Retain serialized workers, zero retries, deterministic cache/seed, bounded top-eight rendering, and byte-safe fixture teardown. |
| T-13-06-06 | Repudiation | full-gate defect repair | low | mitigate | Require regression evidence and summary deviation for every test-proven frontend/backend correction. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → GraphQL Group query | A route token and authenticated viewer identity cross into role-aware group/session reads. |
| Browser → createNightSession mutation | A client-visible manager control requests a persisted draft through the existing authorization boundary. |
| Rails associations → GraphQL response | Session and attendance records are filtered, ordered, and serialized for the current viewer. |

## STRIDE Threat Register (ASVS L1; block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Information Disclosure | `GroupType#sessions` | high | mitigate | Authorize membership and filter drafts server-side before serialization; cover member, outsider, completed, and cancelled cases in `group_query_spec.rb`. |
| T-08-02 | Elevation of Privilege | `createNightSession` UI/mutation path | high | mitigate | Keep the existing backend owner/admin check authoritative, mirror it in the UI, and retain mutation authorization regression coverage. |
| T-08-03 | Denial of Service | nested session attendance reads | medium | mitigate | Eager-load session/attendance/user associations and use loaded-record counts to prevent row-by-row queries. |
| T-08-04 | Spoofing | route token without authenticated membership | medium | mitigate | Return no session summaries when the current user is not a group member/owner, regardless of token knowledge. |
| T-08-SC | Tampering | package supply chain | low | accept | This plan installs no package and uses already-locked dependencies only. |
</threat_model>

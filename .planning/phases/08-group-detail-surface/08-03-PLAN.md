## Phase Goal

**As a** group member, **I want to** view the group's sessions, members, shared collection spotlight, and invite controls in one hub, **so that** group members can coordinate upcoming nights and shared games from one place.

<objective>
Add the bounded shared-collection spotlight slice from deterministic SQL selection through compact social cards.

Purpose: Show the games most meaningfully shared by group members without sending the full shelf to the hub or leaking ownership from outside the group.
Output: Spotlight GraphQL type/resolver/loader scope, generated client contract, compact spotlight component, GroupDetail composition, and focused backend/frontend tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → collectionSpotlight argument | An untrusted GraphQL integer requests a database-ranked subset. |
| Group membership → BggCollection rows | The resolver must distinguish in-group owners from all other owners. |
| Spotlight item → external BGG tab | Persisted game ids construct an outbound public URL. |

## STRIDE Threat Register (ASVS L1; block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Information Disclosure | `GroupType#collection_spotlight` / `#collection` | high | mitigate | Require `viewer_role` before returning rows and prove outsider responses are empty in GraphQL specs. |
| T-08-10 | Information Disclosure | spotlight owner attribution | high | mitigate | Scope OwnersLoader to frozen group-member ids and test an out-of-group owner of the same game. |
| T-08-11 | Denial of Service | `collectionSpotlight(limit:)` | high | mitigate | Clamp to 1..12 and execute one grouped SQL query with a database LIMIT. |
| T-08-12 | Tampering | external BGG navigation | low | mitigate | Build the URL from the typed numeric/string game id only and open with new-tab opener isolation. |
| T-08-SC | Tampering | package supply chain | low | accept | No package is installed; spotlight UI and data access reuse existing vetted code. |
</threat_model>

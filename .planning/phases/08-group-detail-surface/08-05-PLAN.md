<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → member mutations | Untrusted group/user/role ids request destructive or privilege-changing operations. |
| Auth store → menu visibility | Client identity controls UX visibility but cannot replace backend authorization. |
| Mutation result → Apollo cache | A destructive result changes member and shared-ownership state shown in the hub. |

## STRIDE Threat Register (ASVS L1; block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-17 | Elevation of Privilege | remove/update member mutations | high | mitigate | Preserve backend owner/admin and owner-only checks, scope targets to the group, protect owner/self rows, and test direct calls for every role. |
| T-08-18 | Tampering | supplied group/user ids | high | mitigate | Resolve target membership through the supplied Group association and mutate only after all authorization checks pass. |
| T-08-19 | Repudiation | destructive removal | medium | mitigate | Require an explicit member-naming inline confirmation and keep mutation failure visible in the affected row. |
| T-08-20 | Information Disclosure | stale member/owner cache | medium | mitigate | Filter by the server-returned id and refetch Group after success so removed ownership is not presented as current. |
| T-08-SC | Tampering | package supply chain | low | accept | No package is installed; source-owned primitives and existing GraphQL operations are reused. |
</threat_model>

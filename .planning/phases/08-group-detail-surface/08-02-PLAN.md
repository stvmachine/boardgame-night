## Phase Goal

**As a** group member, **I want to** view the group's sessions, members, shared collection spotlight, and invite controls in one hub, **so that** group members can coordinate upcoming nights and shared games from one place.

<objective>
Add the social shared-collection slice to the Group hub and make Browse Library hydrate the existing Collection surface from the locked group-scoped URL.

Purpose: Surface games the group most meaningfully shares without over-fetching the full collection on the hub, while preserving one canonical collection experience for Phase 9 to redesign.
Output: Deterministic backend spotlight selection, group-scoped owner attribution, compact spotlight UI, group-aware CollectionView routing, generated contracts, and focused backend/frontend/browser regressions.
</objective>

| Boundary | Description |
|----------|-------------|
| Browser → collectionSpotlight argument | An untrusted GraphQL limit and route token request a curated group-owned subset. |
| Group membership → collection ownership rows | The resolver must distinguish in-group owners from owners of the same game elsewhere. |
| `/collection?group=` → GroupCollection query | A user-controlled URL token selects the collection source shown by the canonical Collection surface. |

## Phase Goal

**As a** suggestion engine developer and frontend consumer, **I want to** query BGG poll data and a computed best-player-count per thing via GraphQL, **so that** Phase 7 can score games by community poll fit and Phase 9/10 can display per-player-count vote breakdowns.

<objective>
Expose persisted poll data through the GraphQL API: `PollType`, `PollResultType`, a `PollsLoader` (Dataloader source), and `polls` + `bestPlayerCount` fields on the shared `ThingFields` concern. Dump the schema and regenerate frontend codegen types.

Purpose: This slice closes the vertical path — DB poll rows → GraphQL response — with batched loading so collection lists don't N+1.
Output: Two GraphQL types, one loader, ThingFields extension, schema orphan_types registration, dumped `schema.graphql`, and RSpec specs (loader, type, and an integration query spec).
</objective>

- Docker `build` stage emits the React SPA to `/app/public/vite`; the final Ruby stage installs production gems, then copies `/app` from the build stage.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/Kamal proxy → Rails routes | Untrusted Host, method, and path select a public response. |
| Rails controller → generated filesystem | A route must map only to fixed generated files or validated slugs. |
| Build context/environment → public image output | Source, encrypted env file, and build environment coexist while public HTML is produced. |
| GitHub Actions → build/spec process | CI must prove delivery without receiving production credentials. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-05-01 | Spoofing | `DevBlogHostConstraint` | high | mitigate | Strict DNS-name validation plus exact case-insensitive host equality; invalid/unset config cannot activate blog routes; request specs cover hostile values. |

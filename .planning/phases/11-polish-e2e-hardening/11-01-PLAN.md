Storage key chosen for this phase: `boardgame-night:theme`; persisted values are accepted only when they are exactly one of the Theme union values.
Resolved theme is always `light | dark`; `system` consults `window.matchMedia('(prefers-color-scheme: dark)')` and listens for change events.
Root contract: `.dark` present only for resolved dark; `document.documentElement.style.colorScheme` matches the resolved theme.
</interfaces>
